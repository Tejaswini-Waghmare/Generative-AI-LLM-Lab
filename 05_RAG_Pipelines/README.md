# Module 05: Retrieval-Augmented Generation

**Topics:** Chunking, retrieval, citations, abstention, grounded generation.

1. Read `Study_Notes.md`.

4. Compare solutions and write down one limitation.

Requires the repository-root `requirements.txt`. No API key needed.
